# Core64 Linux Distribution
After years of using, upgrading, and rebuilding Josh Devin's Coredistro,
I boot strapped it to AMD64 and called that Core64.

This is a fork of Core3, the 32-bit version, last revisted as a
retrospective project. These are the build scripts I use, influenced by
my use of Slackware (since version 2.3) and Slackware64.

The package info files give the general URL locations for downloading
packages. Contact me privately if an ISO is desired as I no longer
have a website to post to. The current build is a new bootstrap, so is
a beta based on older code, using Linux mainstream kernel 5.4.

Thanks go to many who have contributed hardware in the past, but for
this particular retrospective, revisting past years of work on AMD64
and Intel64, I rely on hardware donated by my coworker, the Professor
(he teaches physics), Jacob Albretsen.
